# Python Messenger

Минимальный консольный мессенджер на Python (TCP):
- `server.py` — сервер, который принимает подключения и рассылает сообщения всем участникам.
- `client.py` — клиент для подключения к серверу.

## Запуск

### 1) Старт сервера
```bash
python3 server.py --host 0.0.0.0 --port 5000
```

### 2) Подключение клиентов
В разных терминалах:
```bash
python3 client.py --host 127.0.0.1 --port 5000 --username alice
python3 client.py --host 127.0.0.1 --port 5000 --username bob
```

Пиши сообщения и нажми Enter для отправки.
Команда `/quit` завершает сессию клиента.
